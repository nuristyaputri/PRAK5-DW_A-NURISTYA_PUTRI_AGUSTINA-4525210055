# Sweet Bites — Website Toko Kue 🍰
NURISTYA PUTRI AGUSTINA-4525210055
## 1. Deskripsi Proyek

Sweet Bites adalah website toko kue sederhana yang dirancang untuk menampilkan pilihan kue, harga produk, informasi tentang toko, dan kontak pemesanan. Website menggunakan desain minimalis dengan warna pastel pink untuk memberikan kesan manis, lembut, dan elegan.

## 2. Tujuan

- Menampilkan produk kue beserta harga dan deskripsinya.
- Memberikan informasi mengenai Sweet Bites.
- Memudahkan pengunjung menemukan informasi pemesanan.
- Menyediakan tampilan yang nyaman di desktop maupun perangkat mobile.

## 3. Fitur Website

- **Beranda:** menampilkan pengenalan Sweet Bites.
- **Menu Kue:** menampilkan tiga pilihan produk kue.
- **Tentang Kami:** menjelaskan cerita dan konsep Sweet Bites.
- **Kontak:** menyediakan tombol untuk menghubungi toko melalui WhatsApp.
- **Navigasi:** membantu pengunjung berpindah ke bagian halaman.
- **Responsive Design:** menyesuaikan tata letak dengan ukuran layar perangkat.

## 5. Teknologi yang Digunakan

- **HTML5:** membangun struktur dan konten halaman.
- **CSS3:** mengatur warna, tipografi, tata letak, animasi sederhana, dan responsivitas.
- **Visual Studio Code:** editor kode yang digunakan untuk mengembangkan website.

## 6. Struktur Folder

```text
Sweet-Bites/
├── index.html
├── style.css
├── README.md
└── Image/
    ├── ultah.jpg
    ├── cupcake.jpg
    └── brownis.jpg
```

## 7. Cara Menjalankan Website

1. Simpan file `index.html` dan `style.css` dalam satu folder.
2. Simpan seluruh gambar yang digunakan di dalam folder `Image`.
3. Pastikan alamat gambar pada `index.html` menggunakan jalur relatif, misalnya `Image/ultah.jpg`.
4. Buka folder proyek melalui Visual Studio Code.
5. Buka `index.html` menggunakan browser atau ekstensi Live Server.
6. Periksa tampilan website pada desktop dan perangkat mobile.

## 8. Konsep Desain

- **Tema:** toko online kue.
- **Warna utama:** pastel pink, putih, dan cokelat gelap.
- **Tipografi:** Arial dan Georgia.
- **Gaya:** minimalis, sederhana, dan elegan.
- **Tata letak:** menggunakan CSS Grid dan Flexbox.
- **Responsivitas:** menggunakan media query untuk tablet dan mobile.

## 9. Catatan Pengembangan

- Pastikan semua gambar tersedia di folder proyek dan gunakan jalur relatif agar website dapat dibuka di perangkat lain.
- Ganti tautan WhatsApp dengan nomor toko yang aktif agar tombol pemesanan berfungsi dengan benar.
- Website saat ini berfungsi sebagai katalog dan media informasi produk. Fitur keranjang belanja dan pembayaran online belum tersedia.

## 10. Penutup

Sweet Bites dibuat sebagai website toko kue dengan tampilan sederhana, informatif, dan responsif. Website ini diharapkan dapat membantu pengunjung mengenal produk serta menemukan informasi pemesanan dengan mudah.
